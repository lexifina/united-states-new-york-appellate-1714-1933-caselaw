# People ex rel. Serwer v. Gaynor

## Majority (PER CURIAM.)

PER CURIAM.
A reference to the papers on file in the county clerk’s office in the action of Serwer v. Serwer shows that the order which is the subject of criticism has been settled, so as to state the grounds upon which the verdict was set aside. Under these circumstances, the application should be dismissed, without costs.
