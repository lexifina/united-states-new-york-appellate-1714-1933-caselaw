# Ellison v. Healy

## Majority (PER CURIAM.)

PER CURIAM.
We think the order is too broad. The defendant should not be required to furnish the particulars specified in the paragraphs numbered from 1 to 5, inclusive. The order should accordingly be modified by striking these out, and, as so modified, affirmed, without costs.
