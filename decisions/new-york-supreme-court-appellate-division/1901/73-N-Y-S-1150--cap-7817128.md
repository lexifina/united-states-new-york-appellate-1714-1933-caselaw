# Weberlowsky v. Raps

## Majority (PER CURIAM.)

PER CURIAM.
As the so-called return in this case is unsigned, it is virtually no return at all, and an order must be made directing the justice to file a return, under section 3055 of the Code of Civil Procedure. As the neglect to procure a proper return seems to be the fault of the appellant, such order will only be made upon stipulation by the appellant to argue the case at the January term.
