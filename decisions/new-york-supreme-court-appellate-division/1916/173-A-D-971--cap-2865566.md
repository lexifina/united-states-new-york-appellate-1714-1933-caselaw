# Carley v. Midland Beach Co.

## Majority

— Order modified by directing that the order for examination be modified so as to authorize the examination only as to the possession, control and condition of the premises upon which plaintiff claims to have been injured, and as so modified affirmed, without costs. No opinion. Order to be settled on notice. Present—Clarke, P. J., Scott, Dowling, Smith and Page, JJ.
