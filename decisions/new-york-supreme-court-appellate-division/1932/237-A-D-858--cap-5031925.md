# Mandel v. Mandel

## Majority

Order denying motion to punish defendant for contempt modified so as to provide that it be without prejudice to a new application on the coming in of the referee’s report under the order granting a reference on condition, in the event that the situation warrant such new application, and as so modified affirmed. Order granting motion for a reference on condition affirmed. No opinion. Young, Carswell, Seudder and Tompkins, JJ., concur; Lazansky, P. J., not voting. [See 235 App. Div. 821.]
