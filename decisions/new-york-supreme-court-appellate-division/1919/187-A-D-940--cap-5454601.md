# Rudolph v. Rudolph

## Majority

Order modified so as to allow no alimony to the plaintiff, but to allow $100 counsel fee, and as so modified affirmed, without costs. No opinion. Jenks, P. J., Mills, Putnam, Blackmar and Kelly, JJ., concurred. .
